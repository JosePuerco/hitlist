Spotify Dashboard öffnen

Warum das Ganze? Spotify erlaubt pro privater App nur 5 Konten. Mit einer eigenen Client ID hast du deinen eigenen Zugang.

App anlegen

  1. „Create app“ antippen
  2. Name und Beschreibung frei wählen, z. B. „Hitlist“
  3. Bei „Redirect URI“ genau diese Adresse eintragen:
https://josepuerco.github.io/hitlist/

Bei „Which API“: Web API ankreuzen, speichern.

Client ID einfügen

In deiner neuen App unter „Settings“ die Client ID kopieren und hier einfügen. Das „Client Secret“ brauchst du nicht.

Konten freischalten

Unter „User Management“ jedes Spotify-Konto eintragen, das deine Hitlist nutzen soll: Name und Spotify-E-Mail. Höchstens 5, dein eigenes zählt mit.

Nach dem Speichern meldet Hitlist dich ab. Danach einmal neu mit Spotify anmelden.
